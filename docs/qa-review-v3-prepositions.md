## Non-blocking observations

- **Fifth-match regularization.** Adding a fifth match question per theme works well in packs 01–02 (new fine-grained categories: at midnight / on a date / in a century / in a year; side / middle / top / corner). In packs 03–04 the added questions (prep3-0092, prep4-0081, prep4-0082) mostly recombine labels already used earlier in the same file — see the minor rows. A contrast/discrimination format (e.g. `in the end` vs `at the end`, `on time` vs `in time`, `except` vs `besides`) would add new value on the fifth match without breaking the quota.
- **Duplicated rule examples across packs.** `at night`, `in the morning` and `at the weekend` appear as rule examples both in `04_idioms_advanced.json` (`idioms-the`) and in `prepositions_01_time_place.json` (`prep-time`). Harmless for the questions, but if the "no duplicate examples" bar is applied set-wide, they should be varied.
- **Non-sequential ids.** After regularization the ids have gaps (`prep1-0086/0087`, `prep3-0091/0092`, `prep4-0081/0082` are the added questions). The schema and the app only require uniqueness, so no action is needed — noted for traceability.
- **No stale explanations found.** Unlike the previous regularized versions, all explanations checked against their current sentences (including the on-time/in-time and during/for items); the only explanation-related issues are the ones listed above.
