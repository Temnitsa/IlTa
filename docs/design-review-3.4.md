# Design review — IlTa 3.4 lesson format (variant A), preposition themes

**Score: 8.5/10 — below the 9 target.** The approved variant A format (numbered lesson cards 01/02/03/04 with «Смысл → Схема → Примеры») is structurally strong and reads clearly: the numbered badges establish a step sequence, hierarchy and typography are consistent across the three themes, and the page is free of the old summary/source clutter. Two visible execution defects are confined to the **«Схема» block** — the very element that defines the format — so the format cannot be called “excellent (9+)” yet; both are localized row-format fixes, not design-system changes. With them applied, the format reads 9.5.

Inspected read-only: `art/screenshots/231_lesson_a.png` (place), `240_lesson_time.png` (time), `241_lesson_verbs.png` (verbs); plus `RuleDetailScreen.kt` (variant-A renderer, `LessonHeading`/`LessonBody`) and the three schema bodies in `prepositions_02_place.json`, `prepositions_01_time.json`, `prepositions_05_verbs.json`. Only this report was written; no gradle.

## What works

- **Numbered lesson cards.** `01/02` lavender number badges + 18sp semibold headings («Смысл», «Схема») create a clear, calm step sequence; badges are visually distinct from the grey `A1/A2` level chip in the progress card and from «Примеры» labels.
- **Hierarchy inside a card.** Heading → 16sp/22 bullets with hanging indent → hairline → 11sp «Примеры» label → 14sp example rows with primary “→”. Consistent across all three screens and with the rest of the app (14dp cards, 1dp hairlines, 16dp margins, 10dp stacks).
- **Three-stage pedagogy reads at a glance** (what it means → the pattern → examples); the progress card stays minimal (chip + «Прогресс темы» + % + bar), no summary/source block.
- **App bars** show short titles («Предлоги места», «Предлоги времени», «Предлог после глагола») that fit one line; the page starts immediately with content.
- Bullets in «Смысл» are short (1–2 lines), the no-prep verb list in 241 (discuss, enter, reach, marry, join, pay a bill) scans well, and example rows stay readable even when a sentence wraps (241).

## Blockers to reach 9 (2, both in the «Схема» block)

1. **Schema rows soft-wrap in the middle of collocations, and wrapped tails are indistinguishable from new rows.** Each schema line is one long monospace `Text` that soft-wraps; the block fits ≈30–33 monospace characters per line, while the authored rows are 54–103 characters. Evidence on all three screens: 231 «…at the door, at / the party, at work», «…in the / room, in Madrid…», «…on / the table, on the wall…»; 240 «…on 16 / May…», «…in / winter, in the morning…»; 241 «…do / something…», «…(попасть) и то / (поймать)». Because continuation lines start at the left margin with the same 22sp line height, the split «the party, at work» looks like a new schema row and the collocation itself is broken. **Fix (content reflow, no design change):** make every schema row fit one monospace line — one preposition group per row, max ~30 monospace chars at 16sp in the card width, e.g. «**at** — точка: at the door · at work», «**in** — внутри: in the room · in Madrid», «**on** — поверхность: on the table · on the wall» — and move the extra collocations into «Примеры». If rows must stay longer, render each row as a hanging-indent block (preposition/meaning as a fixed left column, examples on an indented second line) so wrapped text is visibly a continuation, and never breaks inside a collocation (at least keep «in the room», «on 16 May», «on the table» intact).
2. **The «Схема» row template is not one template across the three themes (and switches mid-block in 240).** 231 uses «prep + RU category = meaning: English collocations» (3 rows); 240 starts the same for at/on/in and then switches to «**by** — к сроку, **until** — до момента, **since** — с начала», «**for** — длительность, **during** — внутри периода, **while** — с предложением», plus a «без предлога: last week…» row (no examples in the last three rows); 241 uses bare «**to**: talk / speak / listen / write, explain, apologise» lists with no Russian meaning at all. The three screenshots are supposed to demonstrate one approved format, but the schema card reads as three different designs. **Fix:** pick one row template and apply it to every row in every theme, e.g. «**prep** — Russian meaning: collocation · collocation · collocation» (2–3 collocations max per row, meaning always present — for verbs: «**to** — адресат: talk to · listen to · explain to»; «**by** — срок: by Monday · by the time»), 4–6 rows per block, with the same ordering logic (at/on/in; by/until/since/for/during/while; etc.).

## Minor notes (optional, not blocking)

- Schema rows mix Russian meanings into the monospace font («at + место = точка»): the block reads like a code listing. If the row template is redone (blocker 2), consider rendering Russian meaning in the regular sans font and keeping only English pattern tokens monospace/bold — same block, immediately more legible.
- «Смысл» and «Схема» currently define the same prepositions twice (240 defines at/on/in in «Смысл» and repeats them in «Схема»; 241 lists the verbs in both). After the schema template fix, keep meanings in «Смысл» and patterns/collocations in «Схема» to avoid duplication and shorten each card.
- The captures show only cards 01–02 of the 4 sections per rule («Смысл», «Схема», «Сравни», «Остальные…»). For a format sign-off, include one capture of cards 03–04 (especially «Сравни», which may need its own layout) so the whole lesson format is covered.
- The next-level check after the fix: verify the schema block on a 360dp-wide device (the narrowest supported width) — at 16sp monospace it fits even fewer characters per line than the 393dp screenshots, so the one-line-per-row target is the safest constraint.

**Bottom line:** 8.5/10. The variant-A shell (numbered lesson cards, hierarchy, typography, examples) is already 9+; only the «Схема» block needs the row reflow (blocker 1) and one consistent row template (blocker 2) to reach the target — both are content/row-format edits, not a redesign of the approved variant.
